# Binaya Chaudhary

Personal portfolio for Binaya Chaudhary, a Shopify app developer and full-stack
engineer based in Bhaktapur, Nepal. Built with Next.js and TypeScript.

Visit the live portfolio: [binayachaudhary04.com.np](https://binayachaudhary04.com.np).

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

The canonical URL and sitemap default to `https://binayachaudhary04.com.np`.
Set `NEXT_PUBLIC_SITE_URL` only if deploying under a different public URL.

```bash
npm run build
npm start
```

## Tech stack

- Next.js App Router, React, TypeScript
- Responsive custom CSS
- Search metadata, Person structured data, sitemap, and robots.txt
