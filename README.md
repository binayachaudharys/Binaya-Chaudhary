# Binaya Chaudhary

Personal portfolio for Binaya Chaudhary, a Shopify app developer and full-stack
engineer based in Bhaktapur, Nepal. Built with Next.js and TypeScript.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

Set `NEXT_PUBLIC_SITE_URL` to the public HTTPS URL before building. This value
is used for canonical metadata and the sitemap.

```bash
npm run build
npm start
```

## Tech stack

- Next.js App Router, React, TypeScript
- Responsive custom CSS
- Search metadata, Person structured data, sitemap, and robots.txt
